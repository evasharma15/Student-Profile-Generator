# Student-Profile-Generator

A beginner-friendly Python program that collects student information
and generates a formatted student profile.

## Features

- Takes student's name
- Takes student's age
- Takes school name
- Displays a formatted profile

## Concepts Used

- Variables
- input()
- print()
- Strings
- Integers

## Example

### Input

Name: Rahul
Age: 14
School: ABC Public School

### Output

===== STUDENT PROFILE =====
Name: Rahul
Age: 14
School: ABC Public School
============================

## How to Run

Make sure Python is installed.

Run:

python student-profile-generator.py
